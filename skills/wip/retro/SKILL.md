# Retro

Trace failure to information/instructions available at the decision. Correct skills only with evidence connecting wording/omission to failure or an explicit user preference; recurrence alone is not causation.

Propose the smallest correction, including none if the cause lies elsewhere. Identify source passage and task revision; describe a before/after comparison with acceptance fixed.

Return causal evidence, exact change, and existing/proposed distinguishing check. Effectiveness remains unverified until observed; code regression checks do not prove model compliance with prose.
