# Be More Ambitious

From [Felix Rieseberg, How to be more ambitious](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/): push on altitude, depth, and range, not just speed.

- **Altitude**: find the goal behind the deliverable: what decision or outcome it exists to drive after it ships, and rewrite the task at that level.
- **Depth**: Rieseberg's prompt:

> I want a deeper version of this task, not a bigger one. Before rewriting it: (1) say what a top professional in this field would do here that I'm not asking for; (2) name the rawest material they would start from instead of what has already been digested for me; (3) name the specific methods and tools they would use; (4) say what, other than you or me, would show the result is right. Then rewrite my prompt to ask for exactly that.

Run the practitioner's actual tools on primary records, not just vocabulary upgrades, and grade the result with an outside check, never in the context that wrote it.

- **Range**: state what the work must do for its audience, then run the distinct specialist perspectives that build, verify, challenge, and sharpen it in parallel. If the rewrite is only longer or busier, question (1) was shallow; start over.
