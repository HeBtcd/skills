# Is This a Thing?

State what the mechanism does in plain words, then search the fields likely to have studied it and match those properties against primary sources. Do the same before building something unfamiliar, what Karl Fogel calls "look around" in [Producing Open Source Software](https://producingoss.com/), Getting Started.

Classify the fit honestly: exact match, special case, partial overlap, loose analogy, or multi-concept synthesis with no single name. If search finds nothing, report "not found", never "brand new." Return the established name, its primary source, and how the user's version differs.

The examiner's vocabulary is [prior art](https://www.law.cornell.edu/uscode/text/35/102): the corpus that can defeat a novelty claim, searched before claiming new. The fit classes map onto patent judgment — exact match is anticipation (35 U.S.C. §102: "patented, described in a printed publication, or in public use, on sale, or otherwise available to the public"), and recombinations that only rearrange what exists are obviousness ([§103](https://www.law.cornell.edu/uscode/text/35/103): "obvious...to a person having ordinary skill in the art"). The verdict is older than patent law — [Ecclesiastes 1:9](https://www.biblegateway.com/passage/?search=Ecclesiastes+1%3A9): "there is nothing new under the sun."
