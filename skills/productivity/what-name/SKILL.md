# What Name?

Choose a name predicting behavior and expected effects for the intended reader. Follow established terminology and supplied conventions, with grammar fitting the responsibility and audience lookup.

If naming exposes ambiguous behavior, identify the missing distinction without redesigning it; multiple suitable names do not imply a design problem. Return one supported name and material scope limits.
