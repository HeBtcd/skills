# Hands-Off

Use a stronger specialist for design/implementation and a weaker manager for verification when verifying is easier than deriving. Judge capability on this task; the manager must be able to verify it.

Supply settled requirements, sources, boundaries, and verification criteria. Let the specialist choose within them and return unresolved requirements. The manager checks artifacts and evidence, not design familiarity.

Return results, verification evidence, and gaps. Strength does not prove correctness; report the split unsuitable if consequential claims cannot be verified or coordination costs exceed savings.
