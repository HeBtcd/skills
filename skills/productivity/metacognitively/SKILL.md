# Metacognitively

Use one independent critic on a bounded judgment or revision: fresh context with source evidence, artifact revisions, prior conclusions, and stated reasons; evidence before explanations. Keep it read-only without further agents; report unavailable if independence cannot hold.

Identify unsupported or revisable steps from evidence to judgment. Critique observable claims, actions, and reasons, not imagined motives; apply the same standard to the critic.

The main agent supplies evidence, correction, or a gap; the same critic checks resolution. Stop when grounds are settled or no new evidence advances the exchange. Return the judgment to retain/revise, grounds, and unresolved dependencies; agreement cannot supply evidence.
