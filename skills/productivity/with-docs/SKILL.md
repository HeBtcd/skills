# With Docs

Write for the supplied reader and purpose, usable without reconstructing the conversation. Preserve consequential sources, reasoning, and unresolved matters; link authoritative material rather than duplicate it.

Distinguish proposals/decisions and observations/inferences. Useful documentation need not imply completed work.

Check sources and intended use; where layout matters, inspect available rendering or mark it unverified. Return the document and material gaps.
