# To Table

Render existing values and relationships as compact key-value tables, preserving names, values, order, nesting, and sentinels. Split for readability with keys sufficient to reconstruct connections.

Mark unknowns. A labeled sample may establish presentation for large structures; honor requested full coverage. Return tables with only necessary connection and coverage notes.
