# Data Flow

From a concrete input, state, or output, trace value sources, transformations, and write destinations. Use compact tables suited to the relationships; preserve source names, consequential order/conditions, and connection keys across tables.

Every displayed output needs a traced or explicitly unknown source; every write needs a destination. Mark inference, scope, and evidence. Trace the existing program without unsupported domain interpretation.
