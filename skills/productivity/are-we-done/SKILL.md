# Are We Done?

Map completion conditions, including required interactions, to the current revision's result and evidence: satisfied, unmet, or unverified. Completion reports alone are not evidence.

Return gaps and evidence needed to close them. Require user acceptance only when specified. Report completion only when all supplied conditions hold; missing criteria or evidence leave the affected judgment unresolved.
